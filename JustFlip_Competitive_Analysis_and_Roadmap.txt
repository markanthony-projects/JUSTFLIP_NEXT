PART 1: CURRENT STATE AUDIT — WHAT JUSTFLIP HAS TODAY
================================================================================

After a complete codebase analysis, here is what JustFlip currently offers:

EXISTING FEATURES:
  ✓ Property listing portal (apartments, villas, plots)
  ✓ City → Zone → Location → Project hierarchical navigation
  ✓ Search with filters (property type, budget, BHK, furnishing, posted by)
  ✓ Sort options (relevance, price asc/desc, newest, popular)
  ✓ Property detail pages with:
      - Project overview, unit table, features/amenities
      - Developer details, price trends (line chart)
      - Explore Map (OpenStreetMap), highlights
      - Reviews system, FAQ section
      - Similar properties, compare carousel
      - Media gallery with images/videos
  ✓ Property comparison tool (side-by-side)
  ✓ Wishlist / favourites (heart button)
  ✓ Lead form / callback request
  ✓ Post property (for owners + brokers)
  ✓ Developer/builder directory with individual profiles
  ✓ Blog section
  ✓ Mortgage/EMI calculator
  ✓ Popular cities section
  ✓ Tagged properties (New Launches, Upcoming, Featured)
  ✓ Authentication (visitor OTP + broker login, JWT)
  ✓ User profile and settings
  ✓ SEO foundations (sitemaps, canonical URLs, meta tags, structured data)
  ✓ Mobile-responsive design with bottom nav
  ✓ Breadcrumb navigation
  ✓ RERA badge component

MISSING / WEAK AREAS (vs competitors):
  ✗ No map-based property discovery (map search)
  ✗ No AI-powered search or recommendations
  — Virtual 360° tours (out of scope by design — high photography/hardware cost)
  ✗ No push notifications / PWA
  ✗ No saved search alerts (price drop / new listing)
  ✗ No locality/neighborhood intelligence pages
  ✗ No programmatic SEO landing pages
  ✗ No user-generated content beyond reviews
  — Exclusively focused on Property Sales & New Launches (Rentals out of scope by design)
  ✗ No home loan integration / pre-approval
  ✗ No agent/broker profiles or marketplace
  ✗ No price estimation / Zestimate equivalent
  ✗ No recently viewed properties
  ✗ No social sharing optimization
  — English-only interface (Multi-lingual support out of scope by design)
  ✗ Limited filtering (no area/sqft, floor, age, possession date)
  ✗ No NRI-focused features
  ✗ No investment analytics or ROI projections

1.1  ADVANCED SEARCH FILTERS (Week 1)
────────────────────────────────────────────────────────────────────────────────

PROBLEM: JustFlip has only 5 filters (property type, budget, BHK, furnishing,
         posted by). Competitors have 15-20+ filters.

WHAT TO ADD:
  • Area range filter (sq.ft min-max slider)
  • Possession status (Ready to Move / Under Construction / New Launch)
  • Possession date (year picker)
  • Number of bathrooms
  • Floor preference (Low/Mid/High rise)
  • Age of property (0-1yr, 1-3yr, 3-5yr, 5-10yr, 10+yr)
  • Facing direction (East, West, North, South)
  • Amenities quick-filter (Pool, Gym, Parking, Garden, Clubhouse)
  • RERA approved only toggle

WHERE TO CHANGE:
  File: src/services/search/searchConfig.ts
    → Add new FilterConfig entries to the `filters` object
    → The UI auto-generates from config (FilterFactory.tsx)

  File: src/app/(justflip)/components/Search/Filters/filters/
    → Create: AreaRangeFilter.tsx (reuse PriceRangeFilter pattern)
    → Create: PossessionFilter.tsx (single-select)
    → Create: AmenityFilter.tsx (multi-select with icons)

  File: src/app/(justflip)/components/Search/Filters/FilterFactory.tsx
    → Register new filter types

  Backend: API needs to support these query parameters

IMPACT: Reduces bounce rate by 20-30% on search pages. Users who can't
        filter precisely leave immediately.

1.2  RECENTLY VIEWED PROPERTIES (Week 1)
────────────────────────────────────────────────────────────────────────────────

PROBLEM: Users browse 10-15 properties per session. Without "recently viewed,"
         they lose track and leave. Every major competitor has this.

IMPLEMENTATION:
  • Create: src/stores/recentlyViewed.store.ts
    → Zustand store with localStorage persistence
    → Store last 30 viewed project IDs + timestamps
    → Auto-prune entries older than 30 days

  • Create: src/hooks/useTrackView.ts
    → Hook called on property detail page mount
    → Records { projectId, name, image, price, location, viewedAt }

  • Create: src/app/(justflip)/components/RecentlyViewed/
    → RecentlyViewedCarousel.tsx (horizontal scroll)
    → Show on homepage (below TaggedProperties)
    → Show on search results page (sidebar or top)

  • Modify: src/app/(justflip)/properties/[city]/[zone]/[location]/[slug]/page.tsx
    → Add useTrackView(projectId) hook call in client wrapper

IMPACT: Increases session duration by 15-25%. Drives repeat visits.
